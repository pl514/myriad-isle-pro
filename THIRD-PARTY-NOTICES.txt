本项目是独立开发的 Windows 桌面工具，产品名称为 Capsule image，中文快捷方式名为「胶囊图」。

- 拖拽导出、区域/窗口/全屏截图、托盘菜单、热键设置、图片编辑器入口、
  独立查看器、动效节奏等交互思路。

四、视觉参考：Folia（AGPL-3.0）
--------------------------------
- 项目：Folia / folia-major，作者 chthollyphile，许可 AGPL-3.0
  https://github.com/chthollyphile/folia-major
  本机安装的是 0.7.27；从安装包元数据看作者仍是 chthollyphile，
  和之前的 0.7.20 是同一个项目的新版，不是另一个作者。
- 本项目的「投射到桌面」歌词舞台在**视觉语言**上参考了 Folia 的
  18 个歌词可视化样式（商籁、凝彩、绘光、花火、町景、雾笺、流光、
  心象、云阶、浮名、倾述、思索、清、时计、群唱、回环、莫奈、镜台）
  以及它们的歌词动画设置面板（随拍开花、随拍推镜、烟花辉光等）。
  但实现是 WPF + C# 的独立重写：
  没有复制 Folia 的 18 个 Pixi/WebGL/Canvas 引擎、dist 资源、缩略图、
  字体或贴图；背景、烟花、雨窗、霓虹、钟表等都是由本地代码程序化画的。
- Folia 的 AGPL-3.0 **允许**修改和再分发，但如果把它的代码直接搬进本项目，
  整个衍生作品需要按 AGPL-3.0 发布并提供源码；本项目仍是 MIT，
  所以这里采用"按视觉语言重新实现"而不是复制源码。
- 字体使用 Windows 自带的 Times New Roman / Segoe UI / SimSun / KaiTi /
  Consolas；没有分发 Folia 的字体文件。
- 如果以后要从 Folia 直接移植代码，请先决定许可证兼容方案（AGPL 或双许可），
  并保留 Folia 的版权与许可文本。

五、音乐面板：各平台接口协议的参考来源
---------------------------------------
本项目音乐面板（QQ 音乐 / 酷狗 / 网易云 / 汽水）的协议实现是 C# 独立重写，
只参考了下列开源项目**公开的协议事实**（接口地址、参数、签名算法），
没有复制它们的 JavaScript 源码、类型定义或资源文件。

1) kugoumusicapi v1.6.0
   - 作者：MakcRe；许可：MIT；完整文本见 licenses/kugoumusicapi-MIT.txt
   - 参考内容：酷狗概念版（lite）参数、MD5 签名、register_dev 设备注册握手、
     二维码登录、歌单与歌曲接口、歌词接口、v5/url 取播放地址。
   - 本项目实现：src/KugouApi.cs（C# 重写）

2) qishui-music-api v0.2.2
   - 作者：sayqz；许可：MIT；完整文本见 licenses/qishui-music-api-MIT.txt
   - 参考内容：汽水音乐车机版 LunaOpenSDK 协议——抖音开放平台扫码授权、
     access_code 换票据、EC P-256 客户端 CSR、bd-ticket-guard 请求签名、
     歌单/歌曲/播放地址/歌词接口。
   - 本项目实现：src/QishuiApi.cs（C# 重写，含 EC 密钥与 PKCS#10 CSR 的 DER 编码）

3) @yakult-green-tea/qq-music-api
   - 许可：MIT；完整文本见 licenses/qq-music-api-MIT.txt
   - 参考内容：仅阅读其 QQ 扫码登录（ptlogin + QQ互联 OAuth + musicu 换票）
     流程，用于评估可行性。本项目**没有采用**该方案，QQ 音乐仍使用
     WebView2 打开官方网页登录。

4) @neteasecloudmusicapienhanced（网易云音乐 API）
   - npm 元数据为 MIT；安装包内未附带 LICENSE 文件，故未在此收录全文。
   - 参考内容：二维码登录使用 type=3、web 平台二维码 URL 附带 chainId、
     以及 requests 默认携带的 PC 客户端 cookie 集合。
   - 本项目实现：src/NeteaseApi.cs（C# 重写）
