# 胶囊动效说明（WPF 原生实现）

本轮给复制版（`Capsule image-copy`）的胶囊加了高级感动效，**全部是 WPF 自带动画**
（`DoubleAnimation` / `ColorAnimation` / `DoubleAnimationUsingKeyFrames` / 缓动函数），
没有引入任何前端库、没有 WebView、没有浏览器动画。

涉及文件：

| 文件 | 作用 |
| --- | --- |
| `src\Motion.cs` | 动效基础层：统一时长/缓动、属性动画封装、平滑滚动 |
| `src\IslandWindow.Motion.cs` | 胶囊与面板的具体动效（`IslandWindow` 的 partial 部分） |
| `src\IslandWindow.cs` | 只在关键位置插入调用（构建胶囊、展开收起、卡片增删、页签、滚轮） |
| `src\Program.cs` | 启动/异常日志改为写入“真正可写”的目录（低权限下也留得下现场） |

## 一、动起来的都是什么

### 胶囊

- **呼吸光晕**：胶囊轮廓外侧一圈“描边 + 模糊”的光环，透明度在 0.16 ↔ 0.36 之间来回，周期 3.8s。
  只在胶囊露出时运行，展开面板后自动停掉，省电。
- **高光扫过**：一条 18° 倾斜的窄高光，每 5.2s 从左往右扫过一次（1.4s 走完，其余时间停住不动）。
  扫完停在画面外，所以不会看到“回扫”。
- **悬停**：上浮 1.5px + 放大 1.5% + 描边提亮 + 外圈光晕点亮，160ms 缓出。
- **按压**：缩到 0.972，90ms；松手用轻微回弹（`BackEase`，振幅 0.3）回到原位。
- **首次出现**：从透明、缩小 0.9、上移 16px 落到位置，约 0.56s 衰减缓动。
- **回到屏幕**（热键显示胶囊）：同样的入场，幅度更小。
- **新内容提示**：胶囊收起时，如果剪贴板来了图片或截图完成，胶囊轻轻跳一下（1.05 倍，0.52s 内回位）。
- 缩放原点固定在**顶边中点**，所以放大/回弹不会被屏幕上沿裁掉一条。

### 面板

- **展开（胶囊长大成面板）**：面板的形变起点被设成「胶囊大小 + 正好盖住胶囊那一格」
  （宽 220/960 ≈ 0.229、高 41/236 ≈ 0.174，再上移 8px 抵消面板的上边距），然后长到 1:1，
  420ms 三次缓出（`CubicEase.EaseOut`），让“由小变大”这一段真正看得见。
  胶囊在 110ms 内原地淡出（它本来就被长出来的面板盖住），所以看不到“先飞走再换一块”。
  面板本体 150ms 淡入先把“形状”立住；内容（页签、卡片）晚 120ms 再淡入，
  这样被压扁的那一小段看不到被挤变形的文字。
- **收起（面板缩回胶囊）**：反向形变，300ms 同样三次缓出；内容先 130ms 淡出，
  面板本身 170ms 淡出并在最后隐藏；胶囊在 140ms 起淡入，同时从 0.94 倍轻弹回 1 倍，
  像是被面板“吐”出来的。
- **卡片错峰入场**：卡片按 20ms 的步进依次进入（首位延迟 120ms，等面板差不多长开再入场，最多 12 张参与），
  每张从 0.93 倍、下移 14px 归位。
- **空状态**：切到“暂无图片 / 暂无文字”时轻微淡入。

### 页签

- “图片 / 文字”不再直接换底色，而是由一块**滑动的渐变底块**在两个页签之间移动（240ms 衰减缓出）。
  文字颜色仍然即时切换，保证可读性不受影响。

### 图片

- **飞进胶囊**：剪贴板来图、截图（窗口/全屏）、拖文件进来时，会有一个缩略图从来源位置
  飞到目标卡片上（400ms 三次缓出，飞行中轻微淡入、落地淡出），落地后卡片再从 0.93 倍
  弹到 1，像是被胶囊“吸”进去。
  - 剪贴板来图：来源点取鼠标位置；面板会先**探出**一下（不抢焦点），图飞进去后 750ms 自动收起
    （胶囊用热键收起时不打扰，只静默加进列表）。
  - 截图：来源就是被截的那块屏幕矩形，面板随后照常打开。
  - 拖文件：来源是拖放的落点，飞完后自动收起。
- **回到胶囊**：单击卡片的放大预览、双击进入的完整查看、右键「钉在桌面」取出的那张图片窗口，
  关闭时都会**由大变小缩回胶囊**（190–220ms）；胶囊同时淡入并弹一下，最后收起
  ——不再是"缩回一个空位"或"啪一下消失"。
  取出的图片窗口在关闭时会先把 × 按钮和缩放手柄藏掉，避免它们原地留在半空。
- 飞行图是一个整块点击穿过的透明窗口（`WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`），
  不挡鼠标、不抢焦点，同时只飞一张，后一张会让前一张先落地。

### 卡通眼睛

未展开的胶囊上原来的「标题文字 + 蓝色圆点」已经去掉，换成一双竖条卡通眼睛
（胶囊本身的光晕、扫光、悬停、按压、入场动效全部保留）。

- **造型**：竖向粗线条、单笔画描边（圆头圆尾），**纯色深蓝 `#2E5FD6`，无渐变、无虚化**；
  左右对称，竖直扁长（线宽 13 : 高 32 ≈ 1:2.5）。睁眼是两条竖条，闭眼是两条横线。
- **位置**：胶囊顶部居中，离胶囊上沿留约 5px 间距，控件背景透明。
- **尺度**：`SizeRatio`（默认 0.56）× 胶囊高度 = 眼睛高度，宽度按设计画布 60:40 推出；
  内部是 `Viewbox`，胶囊自身缩放时眼睛等比跟着缩，不会错位、也不会被圆角裁到。
- **眨眼**：默认睁眼；每 **2–6 秒**随机眨一次；一次 **300ms**（合眼 90ms → 保持 100ms → 睁开 110ms），
  竖条压扁到 0.86 的同时横线淡入，像真的合了一下眼皮。
- **表情接口**：`EyeBlinkControl.Expression`（`Open` / `Happy` / `Sleepy` / `Closed`），
  数据全在 `Expressions` 表里，加表情只要加一条 XAML Path 字符串。
- **开关**：配置项 `EyesEnabled`（`data\settings.txt`，1=显示 0=隐藏），也可用
  托盘右键 →「更多操作」→「卡通眼睛：开/关」随时切换，写回同一个配置项。
  关掉时整双眼睛隐藏（胶囊上什么都不画）并停止眨眼，重新打开会从当前表情继续。
- **省电**：胶囊不可见（面板展开或被热键收起）时不眨眼，只重排下一次。

| 参数 | 位置 | 默认 | 说明 |
| --- | --- | --- | --- |
| `SizeRatio` | `EyeBlinkControl` | `0.56` | 眼睛高度 / 胶囊高度 |
| `IntervalMinMs` / `IntervalMaxMs` | 同上 | `2000` / `6000` | 两次眨眼的随机间隔 |
| `BlinkDurationMs` | 同上 | `300` | 一次眨眼总周期 |
| `ClosedHoldMs` | 同上 | `100` | 闭眼保持时长 |
| `EyeColor` | 同上 | `#2E5FD6` | 纯色深蓝 |
| `EyesEnabled` | 同上 / `data\settings.txt` | `1` | 总开关（关=隐藏整双眼睛） |
| `Expression` | 同上 | `Open` | 表情 |

> 说明：本项目没有 `.csproj`、没有 XAML 编译器（BAML），所以控件是**代码构建布局**的
> `src\EyeBlinkControl.cs`；等价的 XAML 标记见 `docs\EyeBlinkControl.xaml`（参考用，不参与编译）。

### 卡片

- 悬停：放大 2%、上浮 3px。
- 按下：缩到 0.985；松手回弹。
- 开始拖出去（OLE 拖放）：卡片缩到 0.965、上浮 5px，和跟随鼠标的系统拖拽缩略图呼应；结束后回位。
- 右键菜单里的“从胶囊移除”：先缩小淡出 170ms 再从列表移除（列表与 `images.txt` 的写入顺序不变）。

### 托盘菜单

- `TrayMenuWindow` / `MoreMenuWindow` 打开时整体淡入 + 从 0.965 倍轻微上浮到位，约 220ms。

### 滚动

- 滚轮不再“一跳 120px”，而是带阻尼地追向目标偏移（时间常数 48ms）。
  只改 `ScrollViewer` 的偏移量，不接管滚轮事件，卡片拖拽、右键拖出完全不受影响。

## 二、节奏表

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 按压反馈 | 90ms | `CubicEase.EaseOut` |
| 悬停 / 页签滑动 | 160–240ms | `CubicEase.EaseOut`、`ExponentialEase(7)` |
| 胶囊长大的展开 | 420ms | `CubicEase.EaseOut` |
| 面板缩回的收起 | 300ms | `CubicEase.EaseOut` |
| 卡片入场 | 340ms（延迟 120ms 起，20ms 步进） | `ExponentialEase(7)` |
| 卡片移除 | 170ms | `QuarticEase.EaseOut` |
| 胶囊回位 | 280ms | `BackEase(0.3)` |

原则：**进入慢一点、退出快一点**；只有胶囊用回弹（过冲），其他元素一律不过冲。

## 三、为什么不影响现有功能

1. **只动这三类东西**：`Opacity`、`RenderTransform`（`ScaleTransform` + `TranslateTransform`）、
   画笔颜色。不碰 `Width/Height/Margin/Padding`，所以布局、命中测试、`DragMove`、
   `ole32!DoDragDrop` 的坐标链都没变。
2. **动画结束会“落地”**：每次动画完成时把终值写回基础值并清掉动画，
   所以之后代码里直接写 `card.Opacity = 0.45`（拖拽时压暗）依旧立刻生效，
   不会被残留动画“顶住”。
3. **回调带版本号**：同一属性上后来的动画会让前一个动画的完成回调失效，
   因此快速连点（展开→收起→再展开）不会出现“旧的半截动画把新状态改回去”。
4. **面板收起期间关闭命中测试**（`IsHitTestVisible=false`），但文件拖放的
   `DragOver/Drop` 挂在窗口上，拖图进胶囊照旧可用。
5. **手势代码一行没改**：胶囊点击/拖动、卡片左键拖出、右键拖出、剪贴板监听、热键、
   查看器全部保持原样；动效只订阅了 `MouseEnter/Leave` 和 `PreviewMouseDown/Up`
   做视觉反馈，不设置 `Handled`、不抢鼠标捕获。


## 五、怎么自检（不依赖人眼）

- 正常构建：`pwsh -File .\Build.ps1`，产物 `build\Capsule image (copy).exe`。
- 运行期日志：`Program.Boot()` 会按“低权限临时目录 → 普通临时目录 → 程序目录\data”
  找可写位置，写入 `IslandShot-boot.log`；`DispatcherUnhandledException` 的堆栈写入
  `IslandShot-error.log`（同一目录）。低权限启动时以前的日志会静默写不进去，现在能留现场。
- 若需要逐帧看动效，可在离线工具里构造 `IslandWindow` 后用 `RenderTargetBitmap`
  抓关键帧（本轮验证用的就是这套方式：胶囊静止/悬停/高光、面板展开 +70/150/250ms、
  页签滑动 +50/170ms、收起 +60/160ms）。
